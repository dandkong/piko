# 助手工作区

工作区是助手保存指导、记忆、技能和工作材料的长期目录，与源码分离。主会话、旁聊和后台工作共享工作区，但根据各自资源策略加载上下文；不等于共享聊天历史。正式成果放在 `artifacts/`，任务目录属于内部工作空间，不自动成为用户产物。

## 范围与初始化

一个 PIKO_HOME 对应一个 Harness 和长期工作区。默认数据位于 `~/.piko`，工作区可由 `PIKO_WORKSPACE` 单独指定。初始化只补缺失配置、指导文件及目录，不覆盖用户内容；state 必须在工作区之外。已有会话关联的工作区路径不一致时拒绝启动。配置和备份见[应用配置](../operations/configuration.md)和[存储说明](../operations/storage.md)。

## 资源与工具

内建 core 指导随应用发布；工作区 `AGENTS.md` 保存助手身份和通用做事方式，`MEMORY.md` 保存稳定的用户背景和偏好，`memory/YYYY-MM-DD.md` 保存每日事件。指导与技能索引每次模型请求刷新；每日记忆和技能正文按需读取。指导文件完整读取，不静默截断；过大可能超过模型上下文。

技能来自工作区 `.agents/skills` 和应用内建资源，同名时工作区优先；不继承个人 Pi CLI 或祖先指导。Shell 和文件工具使用后端账户权限，Shell 继承后端环境，可能包含敏感凭据。工作区和 cwd 不构成沙箱；附件处理见[附件](attachments.md)。

## 每日与长期记忆整理

主会话闲置 30 分钟后，通常在整理游标后累计至少三条可读外部用户消息时启动独立后台任务；若批次先达到预算，也会整理并推进。任务使用 `read`、`write`、`edit` 维护每日和长期记忆；不纳入旁聊，不提供手动触发工具。批次按完整 entry 边界处理；长期记忆的字符预算是软提示，不是截断或强制写入限制。

整理会合并和更新已有信息，不应把推测或建议写成用户确认，也不应保存凭据。工具仍有本机文件权限；提示不是沙箱。文件写入与 Durable 游标不在同一事务，不提供文件冲突检测或回滚；中断后不自动续跑，后续整理重新读取文件。临时执行按[保留期](../operations/storage.md#临时执行的保留期)回收，不删除记忆文件。

## 验证边界

工作区初始化和记忆整理已在隔离环境检查；真实模型与外部运行环境仍需验证。
