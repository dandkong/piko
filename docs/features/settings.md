# 设置与模型

App 设置管理设备本地的语言、外观，以及全局主模型、后台模型和思考强度。供应商、模型目录、凭据、工具和通道由部署者配置，不在 App 中编辑。

## 页面

语言支持跟随设备、中文和英文；外观支持跟随设备、深色和浅色。偏好保存在当前设备，不翻译用户内容、模型回复或 Telegram。模型选择立即显示，并按修订号保存到后端；保存失败恢复上次确认的选择，结果不确定时重新读取核对。具体反馈见[错误恢复](error-feedback.md)。

## 模型语义

- 主模型统一用于主会话和所有旁聊；App 与 Telegram 共用选择。未选择时不自动挑选目录中的模型，发送被拒绝并保留草稿。
- 后台模型未单独配置时动态跟随主模型；后台思考强度可单独覆盖，但必须是当前模型支持的值。
- 主模型变更在会话空闲或下一轮接纳边界对齐；正在执行的一轮和已启动的后台工作不被切换，新后台工作使用当时的后台策略。

## 配置与 API 边界

`GET /api/settings` 返回模型策略、可用模型摘要和修订号；`PUT /api/settings` 仅修改主/后台模型及思考强度，不读取或写入凭据。模型目录和认证方式见[应用配置](../operations/configuration.md)。该 API 使用单用户访问密钥。

## 验证边界

模型选择及错误恢复已在隔离环境检查；真实供应商、Telegram Bot 和原生真机仍需验证。
