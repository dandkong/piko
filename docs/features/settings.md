# 设置概览

状态：已实现只读设置首页、分类详情及安全概览接口。配置编辑、密钥写入、当前会话模型切换、保存/应用和服务重启尚未接入本页面。

## 入口与交互

- 抽屉左下角“设置”打开共用 `FloatingPanel`，沿用当前浅色、圆角与中性行控件。
- 首页按“模型与能力”“连接”“数据与运行”分组，进入模型、工具与技能、通道、工作区、关于与运行详情。
- 详情在同一浮层内部导航；顶部返回回到设置首页，切页重置内容滚动位置，不重新播放整张浮层的入场动画。
- 只通过明确关闭按钮关闭；点击遮罩、Escape 或系统返回不自动关闭。重新打开回到首页。
- 打开和回前台时读取一次，可手动刷新；没有轮询。关闭时取消未完成请求。读取超时为 10 秒。
- 初次读取失败只显示错误和重试，不用模拟数据填充。刷新失败保留上次内容，并明确说明可能已过期；新请求覆盖旧请求，不让迟到响应覆盖当前状态。

## 可见内容

| 分类 | 当前内容 |
| --- | --- |
| 模型 | 主会话当前原生选择、新主会话默认值、后台默认值，以及可选模型的名称/供应商/上下文能力/思考强度 |
| 工具与技能 | 搜索开关、后端顺序和凭据存在状态；提取开关及动态可用方式；技能名称、描述及是否注入模型索引 |
| 通道 | Telegram 是否配置启用、Bot 凭据是否存在、会话与访问范围说明；不声称已连接 |
| 工作区 | 后端工作区和产物路径、记忆整理门槛、数据与文件权限边界 |
| 关于与运行 | Piko 版本、运行时、模型目录是否有可选项以及配置来源说明 |

模型默认值、工具与 Telegram 配置来自当前进程加载时捕获的安全投影，不重新读取磁盘上的候选配置。主会话当前模型读取 Durable AgentDoc；模型目录和技能元数据按查询时的实际可用项返回。页面不提供服务端已应用修订号或待应用差异，因为当前尚未实现配置写入服务。

main 默认值不覆盖已有主会话选择；background 默认值用于新建的委派、任务执行和记忆整理，已有子会话保留各自配置。这里的供应商凭据状态只表示已配置，不表示网络或账号验证成功。

## API 与边界

- `GET /api/settings` 返回 `shared/settings.ts` 的显式白名单 DTO，响应禁止缓存。
- `POST`、`PUT`、`PATCH`、`DELETE /api/settings` 返回 405，不能用 query 或请求体指定要读取或写入的后端文件。
- 不返回模型 Key、OAuth 凭据、Bot Token、请求 header、供应商 base URL、原始 JSON 或任意环境内容；技能不返回正文和后端路径。
- 异常返回统一错误，不把上游供应商错误或请求细节原样送到概览接口。
- 搜索/提取概览来自实际注册工具时生成的无凭据元数据，避免另造一套后端发现规则。
- 当前 API 仍依赖受信网络或认证代理，不能把只读概览视为已经具备管理认证。配置写入和密钥管理需要另行设计认证、校验、原子保存和应用确认。

## 代码位置

- `server/runtime/settings.ts`：安全启动投影与实时原生选择/目录组合。
- `server/settings/http.ts`：只读 HTTP 和错误脱敏。
- `apps/mobile/src/features/settings/`：页面、内容、Hook 与 API；不直接读取后端文件。
- `FloatingPanel` 的 `headerLeading` 与 `contentKey`：复用内部返回及内容区重置，不影响产物预览默认行为。

## 验证边界

隔离 faux 模型验证了只读方法、凭据/原始配置/技能正文不泄漏、默认值与当前选择分离、磁盘候选不冒充已加载配置、禁止写入及异常脱敏。Chromium 窄屏/宽屏验证了分类导航、刷新失败保留并标注旧内容、重试、明确关闭、Escape/遮罩不关闭、重新打开回首页，以及分类切换的滚动重置；共用产物预览和细滚动条回归通过。Web、iOS、Android 导出与类型检查通过；未用真实 Telegram 凭据做连接测试，原生真机交互尚未验收。
