# 错误反馈与恢复

客户端按失败归属反馈，不把全部错误放到 Toast，也不建立全局错误中心或执行状态副本。

## 载体与位置

- **短暂操作结果**：应用级 `FeedbackToast`，单槽展示 5 秒，不承载必须立即操作的按钮。用于标题生成、任务菜单命令、下载启动失败、缺主模型和帖子生成接纳/冲突等反馈。
- **加载失败**：所属列表或预览中的 `ErrorNotice`，提供具体的重新加载动作。已有内容可继续阅读；失败与“没有内容”的空态互斥。
- **聊天操作失败**：消息列表末尾的局部提示，区分发送、停止、上传和读取；不改成固定覆盖输入框的浮条。历史分页仍在列表顶部恢复旧页。
- **删除失败**：只保留在所属确认框中，可重试原操作；取消后不迁移到页面或抽屉的加载错误。删除期间禁止关闭和重复提交。
- **设置写入失败**：面板打开时在设置内部说明恢复了上次确认的选择，并提供重新读取；面板关闭后失败才使用 Toast，不同时在两处报错。响应丢失不等于服务端未保存，需重新读取核对。
- **中断和能力边界**：重启中断使用中性说明，执行失败保留友好失败提示；两者可关闭，但不会通过通用重试重新执行。文件过大、不支持预览、图片加载失败分别保留能力提示或替代文字。

`ErrorNotice` 只统一外观、无障碍提示与动作布局，业务 Hook/API 仍拥有错误和恢复动作，不存储消息正文或运行状态。删除确认和既有表单继续使用自己的局部错误能力。

## 聊天恢复边界

- 发送每次尝试 10 秒，最多 3 次，始终复用原 `requestId`。主动取消与请求超时分开处理；超时不能静默当作用户取消。
- 结果未确认时保留原请求身份。点击“核对并重试发送”先读取会话，仅仍未确认时重试同一输入；核对失败不另发请求。未解决的输入不会被新的发送覆盖，重试不清掉后来编辑的新草稿。
- 服务端明确拒绝时恢复输入供编辑；不因点击错误提示而以新 ID 重发上一条指令。已接纳但读取失败只重新加载。
- 停止失败只重试原停止命令，保留停止 `requestId`；停止已完成而刷新失败只恢复读取。上传保留成功附件，只补传尚未完成的选择。
- SSE 重连与执行失败/中断提示不会重新提交用户输入。连接与“是否选了可用模型”分开显示；普通断线由既有重连状态承担。

这些请求身份是当前客户端会话内的临时恢复信息，不是持久发件箱；关闭或重载整个应用后不保证恢复尚未确认的本地请求。

## 列表、预览与生成

- Tasks 查询失败可原地重新加载；菜单命令使用短反馈，删除单独保留确认错误。刷新已有列表时不清空卡片。
- 旁聊列表失败与创建、标题生成和删除失败分开；初次失败不显示“还没有旁聊”。创建结果不明时，在当前 Hook 生命周期内复用创建 ID。
- Artifacts 同目录刷新失败保留旧条目；切到另一个目录时不拿旧目录内容充数。下载反馈仅表示能否交给系统打开链接，不保证识别后续 HTTP 下载失败。
- Posts 的首屏/刷新错误与下一页错误分开，分页重试使用失败页游标，不重读第一页。
- 三类共享预览支持“重新加载内容”，不必关闭重开；帖子删除仍只在卡片菜单，预览不增加删除入口。
- 当前 Posts 页面记住本次接纳的生成 ID，手动刷新或回前台时向原生生成查询核对终态；失败提示保留至用户处理/关闭。未确认的生成请求重试原 ID；确定已结束后的“重新生成帖子”才是新请求。没有新增轮询、全局通知或持久生成状态镜像，离开页面后不保证继续追踪该次终态。

## 请求与错误协议

- 共享请求默认 15 秒，聊天读取 10 秒，上传 30 秒，旁聊标题生成 60 秒，永久删除 120 秒；JSON 请求的预算覆盖正文读取。SSE 和发送传输使用自己已有的寿命与超时机制，保持原取消信号。
- `ApiError` 保留 HTTP status 与可选业务 code；非 JSON 响应转换为友好提示，成功状态却无法解析正文按结果不确定处理，不据此认定请求被拒绝。
- 当前使用 `model_unavailable`、`runtime_busy`、`post_generation_busy`、`deletion_blocked` 等 code，不靠文案前缀/子串猜测操作类型。并非所有接口都已枚举业务 code。
- 可预期业务错误保留有用原因；未知客户端异常使用业务 fallback，应用层捕获的 5xx 异常不直接把技术 message 发给客户端。这不是对任意代理、来源服务或所有历史错误的全面脱敏保证。

## 验证边界

类型检查与 Web/iOS/Android 导出通过。隔离脚本覆盖发送去重、主动取消与超时、正文超时和 SSE 取消；独立无登录浏览器在 720px 与 390px 视口使用本地模拟接口注入停止/发送/上传/查询/删除/设置失败，验证恢复动作、局部错误归属、旧内容保留、分页游标与阅读器重试，不调用生产模型或修改生产数据。浏览器模拟不等于原生设备、真实弱网、系统下载或读屏验收。
