# 个性化帖子

Posts 是私人阅读流：助手结合用户背景寻找值得阅读的内容，并说明推荐理由；没有合适内容时可以跳过。帖子不进入主聊天，也不发送 Telegram 或推送通知。

## 生成与阅读

每天服务器本地时间 07:00 自动尝试一次，也可在页面手动生成；停机错过不补跑，生成只允许单并发。卡片展示标题、正文摘录、理由和时间；点击阅读完整 Markdown，可从卡片菜单确认删除。当前不提供编辑或评价。

## 上下文与工具

研究 Agent 从空白子会话开始，接收全局 `MEMORY.md`、最近三个自然日的每日记忆和最近十篇帖子摘要；不自动附带最近聊天。可按需检索主会话可见历史、读取这些帖子的正文及使用网页工具；不能读取旁聊，也没有任意文件写入、Shell、任务或委派工具。资源内容不是操作授权。

## 原生数据与恢复

帖子正文与生成结果保存在 Durable 原生记录，不建立正文或运行状态副本。请求使用 requestId 去重；发布与任务完成一起提交。重启取消未完成生成，不自动重放模型或工具；已发布帖子保留。

## 删除

确认删除会清理帖子及专属生成过程，不删除主聊天、记忆、附件、工作区产物或备份，也不撤销外部副作用。无已发布帖子归属的终态生成记录按[存储保留期](../operations/storage.md#临时执行的保留期)回收。

## API

`/api/posts` 提供列表、正文和删除；`/api/posts/generations` 提供生成、状态查询和停止。生成需要可用模型，可能产生模型及搜索费用。API 未鉴权，应限制在受信网络或认证代理内。

## 验证与限制

调度、上下文、取消与删除在隔离环境检查；原生真机、真实服务的持续生成和内容质量仍需使用验证。
