# 个性化帖子

Posts 是私有阅读流：结合用户背景与近期交流，寻找能拓展理解的内容并解释其意义。选题领域与文章结构不固定；尽量用与主题相关的具体事实、例子或细节支撑文章，避免只停留在抽象判断；没有值得发布的内容时可以跳过。

## 第一版行为

- 在 Posts 标题栏手动触发生成（按钮位于刷新按钮左侧），一次一篇或明确跳过；未接入自动调度。已有生成任务时，服务端拒绝重复请求，客户端显示 warning Toast；新任务接纳后提示已开始，完成后可刷新列表查看。
- 模型返回标题 `title`、Markdown 正文 `body` 和生成理由 `reason`，不要求独立摘要或来源数组。
- Agent 自行决定选题、研究和避免重复；不做内容指纹、语义去重或引用审核门禁。
- 帖子在 Posts 静默展示，不写成主聊天消息，不转发 Telegram、不发送通知。
- 卡片显示 Agent 生成的标题、从正文派生的摘录、生成理由和时间；点击复用内置 `ContentPreviewPanel`，以帖子标题作为可选面板标题阅读正文。帖子 Markdown 中的图片仅加载 HTTPS 地址，非 HTTPS 或加载失败时显示替代文字。
- 可手动刷新、返回前台刷新和分页；不提供编辑、删除、分享或评价管理。

## 上下文与工具

宿主提供完整全局 `MEMORY.md`、最近 3 个自然日（含当天）的每日记忆、最近最多 20 条可见主聊天消息（12,000 Unicode 码点预算）和最近 10 篇帖子摘要。聊天消息按最新优先纳入完整消息，不在预算边界裁切单条正文；旧消息未纳入时通过 `messagesTruncated` 标记。缺失每日文件跳过，不向前补成 3 份。全局记忆不静默截断。

不读取旁聊、隐藏内部输入、工具日志、思考或附件正文。不 fork 主聊天；研究子会话从空白开始，显式接收上下文。

- 复用 `sessions_search`、`sessions_history`：Posts 的宿主绑定允许读取 root 主聊天的可见历史，包括生成期间新增的消息；不允许读取旁聊，其他后台仍不能查询 root。
- Posts 研究 Agent 收到最近 10 篇帖子摘要，不提供全量 `posts_search`；必要时可用 `posts_read` 查看这 10 篇的全文。主聊天仍可用 `posts_search` 按关键词检索已发布帖子。
- 复用 `web_search`、`web_extract`，按需使用，不强制调用顺序或来源字段。
- 研究角色无任意文件读写、shell、任务管理、委派和模型配置工具；不自动注入技能和全局指导文件。

记忆、聊天和网页是源材料，不授予操作权限。工具校验真实角色绑定与会话范围，不依赖 cwd 或提示词假装隔离；没有因此提供 OS 级沙箱。

## 原生数据与恢复

正式内容是同一 Durable SQLite 中 root 下的 `piko.post` entry，`data` 保存标题、正文、理由、时间和生成 task 引用；无 `model`、`head`，不进入主聊天上下文或历史气泡。列表、详情和搜索从原生记录读取，不另建正文镜像。

`piko.posts-generation` 是原生后台 task；回执与研究者绑定分别保存在 `piko.posts-request`、`piko.posts-context`，不复制 Run 状态。相同请求返回同一任务，不同输入复用 requestId 报冲突；一次只运行一个生成任务。

发布与任务完成同一事务提交。取消可先投影为 `stopping`，收尾后为 `stopped`；已发布不能靠取消回滚。重启取消未完成生成、清空研究会话遗留输入，不自动重放模型或工具；已提交帖子保留。

## API

| 接口 | 行为 |
| --- | --- |
| `POST /api/posts/generations` | `{ requestId }`，由 Agent 自行选题并启动生成，返回 202 和生成引用 |
| `GET /api/posts/generations/:id` | 原生状态，完成时返回 postId，跳过时返回理由 |
| `POST /api/posts/generations/:id/stop` | 请求取消并返回当前状态 |
| `GET /api/posts?before=&limit=` | 倒序卡片分页，默认 20、最多 50 条 |
| `GET /api/posts/:id` | 标题、正文、理由和时间 |

```bash
curl -sS http://127.0.0.1:8787/api/posts/generations \
  -H 'Content-Type: application/json' \
  -d '{"requestId":"posts-trial-001"}'
```

需要配置可用主/后台模型。接口依赖受信网络或部署代理，没有内建鉴权；生成会产生模型和可能的搜索费用，刷新列表不会触发生成。

## 验证与限制

隔离 SQLite/faux 模型覆盖实际生成、三天上下文、root 历史边界、工具调用与旁聊排除、标题/正文/理由、请求去重与冲突、单并发、分页、跳过/非法结果、取消收尾、重启不重放，以及无主聊天输出。类型检查及 Web/iOS/Android Expo 导出通过。共享浏览器验证了 390px 与桌面卡片、生成理由、正文预览、长文滚动、空态、失败重试，并回归产物 Markdown 预览。生产已完成未指定主题、带独立标题的新帖生成；期间 root 只新增帖子 entry，没有新增聊天消息。共享阅读器已验证 Agent 标题、无正文标题的组合和真实任务结果，且不会向正文拼入生成理由。原生真机显示尚未验证；单次真实试跑和 faux 通过不代表持续选题、资料或文章质量保证。
