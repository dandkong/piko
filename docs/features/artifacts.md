# 产物浏览

Artifacts 是助手保存的正式成果入口，浏览工作区 `artifacts/`；任务目录和其他工作材料不自动并入。

## 浏览与交互

页面支持文件夹导航、面包屑、名称或修改时间排序、刷新，以及文件下载和确认后删除。文件夹优先；删除目录会递归删除其内容。当前不提供创建、重命名、移动或目录下载。查询、预览和删除错误留在对应上下文，见[错误反馈与恢复](error-feedback.md)。

## 内置预览

支持 Markdown 和常见文本/代码文件，UTF-8 解码，单文件上限 1 MiB；不支持或过大的文件可下载。HTML/SVG 按文本展示，不执行；Markdown 图片只加载 HTTPS，失败显示替代文字。聊天附件、帖子和执行结果复用阅读组件，但各自的数据范围不变。

## HTTP

`GET /api/artifacts` 列目录，`GET /api/artifacts/content` 读取允许预览的文本，`GET /api/artifacts/download` 下载文件，`DELETE /api/artifacts` 删除文件或目录。路径均相对 `artifacts/`；拒绝绝对路径、越界、隐藏路径与符号链接，不能删除根目录。API 未鉴权，访问控制依赖部署环境。

## 验证边界

Web 与隔离环境已检查浏览、排序、预览和删除；原生设备的布局、读屏及下载行为仍需验证。
